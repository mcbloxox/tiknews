Privacy Policy

Last updated: 20 July 2026 · Operated by NightHalo_

1. What this is

This policy covers an automated content publishing tool ("the Tool") operated by a single individual. The Tool reads publicly available entertainment news feeds, generates image cards summarising those stories, and publishes them to one TikTok account owned and operated by NightHalo_.

The Tool is not a product offered to other people. It has no users other than its operator, no sign-up, no accounts, and no public interface. It is a personal publishing workflow.

2. Information collected from TikTok

When the operator authorises the Tool through TikTok Login, the following is stored:

  • An OAuth access token and refresh token for the operator's own TikTok account
  • Basic account information returned by the user.info.basic scope (display name, avatar URL, open ID), used only to confirm the correct account is connected
  • Publish identifiers returned by TikTok after a post is created, used to check whether publishing succeeded

The Tool requests only two permissions: user.info.basic and video.publish. It cannot read the operator's videos, followers, messages, comments, or analytics, and it does not request access to any other TikTok account.

3. Information collected from anyone else

None. The Tool collects no information from TikTok viewers, followers, or any other person. It does not use cookies, analytics, tracking pixels, or advertising identifiers. It does not build profiles of any individual. Nobody other than the operator can log in to it, because there is nothing to log in to.

4. News content

The Tool reads publicly published RSS feeds and public web pages from news organisations. It stores article headlines, summaries, publication timestamps and source URLs in order to remove duplicates and to verify that quoted text matches its source. This is publicly published journalism, not personal data gathered about individuals.

Published cards name their source. If you believe a card misstates something about you or misattributes a quote, contact filipgorczynski5@gmail.com and it will be corrected or removed promptly.

5. How information is stored

  • Tokens are held in GitHub Actions encrypted secrets and are never written to the repository, logs, or any public file
  • News data and generated images are stored in a GitHub repository
  • Generated images are served publicly from media.nighthalospace.online so that TikTok can download them during publishing

6. Third parties

The Tool sends data to the following services, and to no others:

  • TikTok — to publish content, under TikTok's own privacy policy
  • GitHub — hosting, scheduling and storage
  • Anthropic — article text is sent to Claude to draft card copy, where the API is used for that step

No information is sold, rented, or shared for advertising purposes. There is nothing to sell.

7. Retention and deletion

  • News data older than 14 days is deleted automatically
  • Generated images are deleted 7 days after publishing
  • Tokens are deleted immediately if the operator revokes access

The operator can revoke the Tool's access at any time from TikTok's Settings → Security and permissions → Manage app permissions. Doing so invalidates the stored tokens.

8. Children

The Tool is not directed at children and collects no information from anyone, including children. Its output is subject to TikTok's own age policies.
